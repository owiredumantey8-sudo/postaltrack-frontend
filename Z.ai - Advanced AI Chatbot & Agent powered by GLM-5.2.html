1.2 Threats Discussion

1.2.1 RANSOMWARE

Definition: Malicious software that encrypts files and demands payment for decryption keys.

How It Works:

text
[Entry Point] → [Lateral Movement] → [Encryption] → [Ransom Demand]
↓ ↓ ↓ ↓
Phishing/ Network Files Locked Bitcoin/
RDP Exploit Propagation Backups Deleted Payment

Impact on Financial Institutions:

  • Complete operational shutdown
  • Data exfiltration before encryption (double extortion)
  • Regulatory fines for data breaches
  • Reputational damage

Examples:

  • Colonial Pipeline (2021): $4.4M ransom paid
  • Kaseya (2021): Affected 1,500+ businesses
  • Costa Rica Government (2022): $20M demanded

Mitigation Strategies:

  • Regular offline backups (3-2-1 rule)
  • Network segmentation
  • Email filtering and user training
  • Endpoint Detection and Response (EDR)
  • Patch management

Encryption transforms readable data (plaintext) into an unreadable format (ciphertext) using cryptographic algorithms and keys.

SYMMETRIC ENCRYPTION (Same key for encrypt/decrypt):
• Faster performance
• Key distribution challenge
• Examples: AES-256, 3DES

ASYMMETRIC ENCRYPTION (Public/Private key pair):
• Slower but more secure key exchange
• Public key encrypts, Private key decrypts
• Examples: RSA-2048, ECC-256

TASK 3: IP Addressing and Subnetting Design (20 Marks)

3.1 Given Information

IP Address: 192.168.1.10/23

3.2 Step-by-Step Calculation

Step 1: Analyze the Given IP and Subnet Mask

Binary Representation:

text
IP Address: 192.168.1.10
Binary: 11000000.10101000.00000001.00001010

Subnet Mask: /23
Binary: 11111111.11111111.11111110.00000000
Decimal: 255.255.254.0

Network Portion vs Host Portion:

text
┌─────────────────────────────────────────────────────────────┐
│ /23 SUBNET BREAKDOWN │
├─────────────────────────────────────────────────────────────┤
│ │
│ 11000000.10101000.0000001│0.00001010 │
│ ├────────────────────────┤├────────────────────────────────┤│
│ NETWORK (23 bits) HOST (9 bits) │
│ │
└─────────────────────────────────────────────────────────────┘

Step 2: Determine the Network Address

To find the network address, we set all host bits to 0:

text
IP: 11000000.10101000.00000001.00001010
Subnet: 11111111.11111111.11111110.00000000
AND Result:11000000.10101000.00000000.00000000

Network Address: 192.168.0.0/23

Note: The IP 192.168.1.10 falls within the 192.168.0.0/23 network because:

  • Third octet range: 192.168.0.0 to 192.168.1.255
  • .1.10 is within this range

Step 3: Calculate Block Size

text
Block Size = 2^(8 - (subnet_mask_octet_3 mod 256))
= 2^(8 - 254)
= 2^1
= 2 (in the third octet)
OR simply:
Block Size = 256 - 254 = 2

Block size of 2 in third octet means networks increment by 2:

  • 192.168.0.0/23
  • 192.168.2.0/23
  • 192.168.4.0/23
  • etc.

Step 4: Calculate Total Usable Hosts (Original /23)

text
Formula: Total Hosts = 2^host_bits
Usable Hosts = 2^host_bits - 2

Host bits = 32 - 23 = 9

Total IP addresses = 2^9 = 512
Usable hosts = 512 - 2 = 510

Subtracting 2 for:
- Network address (first IP)
- Broadcast address (last IP)

Step 5: Subnet Further for Branch Requirements

For a bank branch, we need multiple subnets for different purposes. Let's subnet the /23 into /26 subnets:

Why /26?

  • Provides 62 usable hosts per subnet (sufficient for most departments)
  • Creates 8 subnets from one /23
  • Allows proper network segmentation

Calculation for /26:

text
New subnet mask: /26
Binary: 11111111.11111111.11111111.11000000
Decimal: 255.255.255.192

Number of subnets = 2^(new_prefix - original_prefix)
= 2^(26 - 23)
= 2^3
= 8 subnets

Usable hosts per subnet = 2^(32-26) - 2
= 2^6 - 2
= 64 - 2
= 62 hosts

Block size (4th octet) = 256 - 192 = 64
